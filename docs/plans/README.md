# Implementation Plans

Step-by-step implementation plans produced by the `writing-plans` skill, one file per
piece of work. A plan is written **after** its spec in `docs/specs/` is approved and
**before** any code is written.

Naming: `NNN-short-slug.md` (e.g. `001-postgres-serving-layer.md`).

A plan should be executable by a fresh session with no prior context: numbered tasks,
the files each one touches, and the verification command that proves it done.
